# GenAI-Eshop

> Practical GenAI-Eshop application using [microsoft/agent-framework](https://github.com/microsoft/agent-framework), multi-agent orchestrations, Mcps tools, A2A agents, semantic search and more.

> **Tip**
> This project is in progress. I add new features over the time. You can check the [Release Notes](https://github.com/mehdihadeli/genai-eshop/releases/).

> **Important Note**: We will migrate this GenAI-Eshop application to the [Semantic Kernel](https://github.com/microsoft/semantic-kernel) instead of [microsoft/agent-framework](https://github.com/microsoft/agent-framework) in a [sepereated repository](https://github.com/mehdihadeli/genai-eshop-semantic-kernel). You can check their differences in a practical application here.
